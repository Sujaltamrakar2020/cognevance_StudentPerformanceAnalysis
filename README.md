# Student Performance Analysis

## Objective
Analyze student academic performance and identify patterns using attendance, study hours, assignments, midterm scores, and final exam scores.

## Tools
- Excel
- MySQL (optional)
- Python (optional)
- Power BI (optional final dashboard)

## Files
- `student_performance_data.csv` — 200-student dataset
- `Student_Performance_Analysis.xlsx` — ready-made Excel analysis and charts
- `student_performance_analysis.py` — optional Python analysis
- `student_performance_analysis.sql` — optional MySQL queries
- `README.md` — project guide

## Main Questions
1. What is the average student score?
2. Which department has the highest average score?
3. What is the overall pass rate?
4. How are grades distributed?
5. Does attendance relate to overall performance?
6. How does study time relate to performance?

## Suggested Resume Description
Built a Student Performance Analysis project using Excel, MySQL and Python to clean, analyze and visualize 200 student records. Created KPI analysis, department-wise performance reports, grade distribution, and attendance-vs-score analysis to generate actionable insights.
